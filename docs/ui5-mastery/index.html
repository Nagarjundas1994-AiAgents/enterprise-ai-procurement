Cheat sheets

Lifecycle

onInit once → onBeforeRendering each render → onAfterRendering DOM ready → onExit cleanup. Route wiring in onInit; DOM libs in onAfterRendering (once); detach in onExit.

Routing

manifest routes (name/pattern/target) + targets (viewName/level/controlId/aggregation). navTo(name, params); attachPatternMatched in onInit; back via History with deep-link fallback.

Models

JSONModel (UI state) · ODataModel V2/V4 (backend) · ResourceModel (i18n). setModel(m) default, setModel(m,"x") named → {x>…}. Update via setProperty — never raw mutation.

Binding

Modes: one-way (lists), two-way (forms), one-time (static). Types: property, aggregation (items), element (bindElement), expression ({=…}). Context = pointer to one object.

OData V2

read/create/update/remove + setDeferredGroups + submitChanges. Options: $filter $select $expand $orderby $top $skip $count (binding opts drop the $).

OData V4

bindList/bindContext, requestContexts/requestProperty, list.create(), ctx.setProperty/delete(), submitBatch, requestSideEffects. Params keep $.

CRUD

Validate → busy → send → toast + targeted refresh → errors to MessageBox → busy off (finally). Confirm deletes. Disable save while busy.

Fragments

Fragment.load({name, controller}) → cache promise → addDependent → open. Destroy in onExit.

Tooling

ui5 serve dev+proxy · ui5 build --all → dist/Component-preload · deploy dist/ · never commit dist/.

Debugging

First error first. Inspector (bindings) → Network (OData) → Support Assistant (rules) → MessageManager (messages). Empty table = path/model-name mismatch.

Performance

$select + growing + one-way lists; batch writes; preload bundle; destroy dialogs; lazy heavy libs; profile before optimizing.

Fiori

Floorplans (List Report/Object Page/FCL), horizon theme, Cozy/Compact, launchpad integration, keyboard + screen-reader pass.
